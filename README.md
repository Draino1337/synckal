# synckal

Смотрим YouTube с друзьями синхронно. Комната по ссылке, общая очередь, чат.
Нажал паузу — пауза у всех, перемотал — перемотало у всех.

**Сайт: https://synckal.onrender.com**

По мотивам sync-tube.de, дизайн — из govnoreview: тёмная пиксельная тема, лавандовый акцент,
ступенчатые углы, звёздное небо и ASCII-котик в логотипе.

## Возможности

- Комната в один клик, ссылка-приглашение `/r/<код>`, без регистрации
- Синхронный плеер: play / pause / перемотка / скорость; подстройка, если кто-то отстал больше чем на секунду
- Очередь: добавить по ссылке (watch, youtu.be, shorts, live, embed, `&t=`), «следующим», «сейчас»,
  перетаскивание, перемешать, очистить, автопереход к следующему видео
- Названия и превью подтягиваются сами
- Чат; ссылку на YouTube из чата можно одним нажатием отправить в очередь
- Ведущий (корона) и модераторы; режим «управляют все» или «только ведущий и модераторы»
- Голосование за пропуск, если управлять могут не все
- Выгнать участника (обратно в эту комнату он не зайдёт)
- Громкость и полноэкранный режим у каждого свои; субтитры вкл/выкл, кнопка «открыть на YouTube»; горячие клавиши: пробел/K, ←/→, F, M, C

## Запуск

```
npm install
npm run dev
```

Откроется http://localhost:5173 (Vite), сервер комнат — на :3000.

Прод:

```
npm run build
npm start
```

Всё на одном порту (`PORT`, по умолчанию 3000): сервер раздаёт `dist/` и держит WebSocket `/ws`.

## Хостинг

Сейчас работает на Render (бесплатный план, настройки — [render.yaml](render.yaml)): каждый пуш в main выкатывается сам.
Бесплатный сервис засыпает после ~15 минут без посетителей; первый заход после сна грузится до минуты.

Нужен сервер с Node.js 20+ и поддержкой WebSocket — GitHub Pages не подойдёт.
Подходят Render, Railway, Fly.io или свой VPS: команда сборки `npm install && npm run build`, запуска — `npm start`.

Комнаты хранятся в памяти: после перезапуска сервера они пустые.

## Устройство

- `server/index.mjs` — HTTP + WebSocket (`ws`). Состояние плеера: позиция `pos` в момент `at`
  по серверным часам; клиент досчитывает текущую позицию сам.
- `src/lib/room.ts` — подключение, переподключение, сверка часов по ping/pong.
- `src/components/Player.tsx` — YouTube IFrame API и цикл подстройки.
- `src/styles/pixel.css`, `src/lib/pixel.ts`, `src/components/Starfield.tsx`, `src/components/AsciiLogo.tsx` — из govnoreview.
