# synckal — план

Совместный просмотр YouTube с друзьями, по мотивам sync-tube.de. Дизайн — из govnoreview:
тёмная пиксельная тема, лавандовый акцент, ступенчатые углы, звёздное небо, ASCII-логотип с котиком.

## Что умеет (как у sync-tube)

- [x] Комната в один клик, ссылка-приглашение `/r/<код>`, вход по коду с главной
- [x] Ник (запоминается в браузере), цвет у каждого участника
- [x] Синхронный плеер: play / pause / перемотка / скорость у всех одновременно
- [x] Коррекция рассинхрона: часы клиента сверяются с сервером; расхождение от 0,1 с догоняется скоростью
      (±5–10%, без скачка), от 3 с — перемоткой с упреждением на догрузку; своя пауза и перемотка — сразу
- [x] Плейлист: добавить по ссылке (watch, youtu.be, shorts, live, embed, id), «следующим»,
      «включить сейчас», удалить, поднять/опустить, перемешать, автопереход к следующему
- [x] Названия и превью видео подтягиваются автоматически (oEmbed)
- [x] Голосование за пропуск видео (больше половины — пропуск)
- [x] Чат с системными сообщениями (кто зашёл, что включили)
- [x] Список участников: ведущий (корона), модераторы; несколько вкладок одного человека — одна строка
- [x] Выгнать участника — обратно в эту комнату он не зайдёт
- [x] Права: ведущий решает, могут ли все управлять плеером и плейлистом или только ведущий и модераторы
- [x] Ведущий может назначать модераторов и передавать корону; ушёл ведущий — корона
      переходит к самому давнему участнику, вернулся — получает её обратно
- [x] Главная: ASCII-Сатурн из govnoreview на заставке, «Создать комнату» и «Войти», ниже — живой
      список комнат: превью видео, что играет, кто внутри (ведущий может скрыть комнату с главной)
- [x] Подтверждения вторым нажатием вместо системных диалогов (очистить очередь, передать корону)
- [x] Качество видео у каждого своё: Авто, 480p–4K. setPlaybackQuality в YouTube давно не работает,
      поэтому плеер раскладывается в нужном разрешении и ужимается под экран (ниже 480p встроенный плеер не опускается)
- [x] Интерфейс YouTube поверх видео спрятан: плеер выше экрана, заголовок и нижние кнопки обрезаны;
      вместо заставки с красной кнопкой и концовки — своя обложка
- [x] Превью при наведении на дорожку: кадр из раскадровки YouTube, время и глава; границы глав на дорожке
- [x] Лайки, дизлайки (оценка Return YouTube Dislike) и просмотры под названием видео
- [x] Создатель комнаты может её распустить (красная кнопка, вторым нажатием) — все выходят, код больше не занят
- [x] Комната в один экран без прокрутки: ссылка над плеером, плеер подстраивается под высоту окна,
      чат и очередь — вкладки одной панели со счётчиком непрочитанного; «Пригласить» рядом с «Распустить»
- [x] Субтитры вкл/выкл (по умолчанию выкл, клавиша C), кнопка «открыть на YouTube» с текущей секундой
- [x] Свои кнопки плеера (громкость у каждого своя), полноэкранный режим, «присоединиться»,
      если браузер заблокировал автозапуск

- [x] Реакции поверх видео у всех (кнопки под видео, клавиши 1–6), непрочитанные сообщения в заголовке вкладки
- [x] Превью ссылки на комнату в мессенджерах: что играет, сколько человек, обложка видео
- [x] Сервер на Render не засыпает: раз в 10 минут стучится сам к себе

## Устройство

- `server/index.mjs` — Node.js + `ws`. Хранит комнаты в памяти, раздаёт собранный фронтенд из `dist/`.
  Состояние плеера: `{videoId, playing, pos, at, rate}` — позиция в момент `at` по серверным часам;
  клиент сам досчитывает текущую позицию. Пустая комната удаляется через 10 минут.
- `src/` — React + Vite + TypeScript, YouTube IFrame API.
  - `lib/room.ts` — подключение по WebSocket, переподключение, сверка часов (ping/pong).
  - `components/Player.tsx` — плеер и цикл синхронизации раз в 500 мс.
  - `pages/Home.tsx`, `pages/Room.tsx` — главная и комната.
  - `styles/pixel.css`, `lib/pixel.ts`, `components/Starfield.tsx`, `components/AsciiLogo.tsx` — из govnoreview.

## Запуск

```
npm install
npm run dev      # сервер :3000 + vite :5173 с прокси
npm run build && npm start   # прод: всё на :3000
```
